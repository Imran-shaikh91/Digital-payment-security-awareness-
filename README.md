# Digital Payment Security Awareness

A responsive, static educational website for a student project. It is built with HTML, CSS and JavaScript and can be hosted on GitHub Pages.

## Modules included
1. Understand digital payments
2. Essential safety practices
3. Recognise common warning signs
4. Before-you-pay interactive checklist
5. Awareness quiz with score and feedback
6. What to do if you suspect fraud (India)

## Run locally
Open `index.html` in a web browser. No installation or server is required.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new repository (for example, `digital-payment-security-awareness`).
2. Upload all three website files: `index.html`, `style.css` and `script.js`. You may also upload this README.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish the site. The Pages section will show your website address.

## Important
- This is an educational awareness prototype only. It does not process payments, connect to bank accounts, store survey answers or collect personal/financial information.
- Never add real UPI PINs, OTPs, passwords, card details or bank credentials to this project.
- The fraud-reporting information is for India. For suspected financial cyber fraud, contact your bank immediately, call 1930, and use the official portal: https://cybercrime.gov.in/
- Recheck official instructions periodically because procedures can change.
